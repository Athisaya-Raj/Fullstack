================================================================================
                              5-MINUTE SETUP
================================================================================

1. BACKEND SETUP
   cd backend
   cp .env.example .env
   pip install -r requirements.txt
   python -m uvicorn app.main:app --reload --port 8000

2. FRONTEND SETUP (in new terminal)
   cd frontend
   npm install
   npm run dev

3. MONGODB
   mongod (in another terminal)

4. VERIFY
   Backend:  http://localhost:8000/docs (Swagger UI)
   Frontend: http://localhost:3000
   Test Login: test@example.com / password123

================================================================================
                            API ENDPOINTS
================================================================================

Health:
  GET /health/status                    → Check system status

Auth:
  POST /auth/signup                     → Register new user
  POST /auth/login                      → Get JWT token
  GET /auth/me                          → Get current user

Cases:
  POST /cases                           → Create case (auto-classified!)
  GET /cases/{id}                       → Get case details
  GET /cases/me                         → List your cases
  PATCH /cases/{id}/status              → Update case status
  POST /cases/{id}/assign               → Assign case to lawyer

Appointments:
  POST /appointments                    → Book appointment (detects conflicts!)
  GET /appointments/{id}                → Get appointment
  GET /appointments/me                  → List your appointments
  PATCH /appointments/{id}              → Reschedule
  POST /appointments/{id}/cancel        → Cancel

Try them all: http://localhost:8000/docs

================================================================================
                            TROUBLESHOOTING
================================================================================

Backend won't start?
  → Check MongoDB is running (mongod)
  → Check .env file exists
  → Check port 8000 is free

Frontend can't connect?
  → Verify backend running on localhost:8000
  → Check frontend .env VITE_API_URL
  → Check CORS in backend config

Database disconnected?
  → Verify MongoDB running
  → Check MONGODB_URI in .env
  → Try: mongosh to test connection

Stuck?
  → Read PROJECT.md (comprehensive guide)
  → Check troubleshooting section
  → Verify all prerequisites installed

================================================================================
                            DEVELOPMENT WORKFLOW
================================================================================

To Add a New Feature:

1. Create model: backend/app/models/feature_model.py
2. Create service: backend/app/services/feature_service.py
3. Create router: backend/app/routers/feature_router.py
4. Register router in: backend/app/main.py
5. Create service wrapper: frontend/src/services/featureService.js
6. Create React component: frontend/src/components/FeatureForm.jsx

Full details: Read PROJECT.md → Development Guide
